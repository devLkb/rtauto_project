# claudeDocs — AI 세션끼리 주고받는 인수인계 자리

이 디렉터리는 **AI 세션이 서로 작업을 넘겨주기 위한 곳**이다. 사용자도 언제든 읽을 수 있게
쉬운 말로 쓰되(최상위 [`CLAUDE.md`](../CLAUDE.md) 원칙 4), 주 독자는 **다음 세션의 AI**다.

## 왜 있는가

이 프로젝트는 한 사람이 혼자 맡고 있고, 작업 중인 컴퓨터가 불안정해서 **대화가 도중에
끊기는 일이 잦다.** 그때마다 사용자가 새 대화를 열고 "지금 상황이 이렇다"를 처음부터
다시 설명해야 했다. 그 설명을 **파일로 대신하는 것**이 이 디렉터리의 목적이다.

## 구성

| 경로 | 내용 |
|---|---|
| [`BACKLOG.md`](BACKLOG.md) | **앞으로 구현해야 하는 기능 목록.** 상태(대기/진행중/완료)를 여기서 관리한다. 파일 하나로 유지한다 |
| `daily/YYYY-MM-DD.md` | **날짜별 작업 기록.** 그날 무엇을 했고, 무엇이 검증됐고, 다음에 뭘 해야 하는지 |

날짜 문서를 나누는 이유: 한 파일에 전부 쌓으면 사람도 AI도 읽지 못한다. 하루치만 읽으면
바로 이어받을 수 있게 쪼갠다.

## 세션 시작할 때 (AI가 할 일)

**순서대로 읽는다. 이것만 읽어도 이어받을 수 있어야 한다.**

1. 이 파일(`claudeDocs/README.md`) — 규칙
2. [`BACKLOG.md`](BACKLOG.md) — 무엇이 남아 있는지, 지금 무엇이 진행 중인지
3. `daily/` 에서 **가장 최근 파일 1~2개** — 직전 세션이 어디까지 갔는지

```bash
ls claudeDocs/daily/ | sort | tail -3
```

그다음 **`git status --short --branch` 와 `git log --oneline -5` 로 실제 리포 상태를
대조한다.** 문서와 리포가 다르면 **리포가 사실**이고, 문서 쪽을 고친다.

## 세션 진행 중에 (가장 중요한 규칙)

**끝날 때 몰아서 쓰지 않는다. 한 단계가 끝날 때마다 그 자리에서 오늘 문서에 적는다.**

대화가 언제 끊길지 모르기 때문이다. 몰아서 쓰려다 끊기면 기록이 통째로 사라진다.
아래 시점마다 오늘 날짜 문서를 갱신한다.

- 파일을 고쳤을 때 (무엇을, 왜)
- 실험·테스트를 돌려서 결과가 나왔을 때 (명령과 결과 숫자)
- 사용자가 결정을 내렸을 때 (무엇을 승인했고 무엇을 보류했는지)
- 막혔을 때 (무엇을 시도했고 왜 안 됐는지)

## 세션 끝낼 때

1. 오늘 문서의 **"다음에 할 일"** 을 반드시 채운다. 비어 있으면 인수인계가 아니다.
2. 끝난 항목이 있으면 [`BACKLOG.md`](BACKLOG.md) 의 상태를 바꾸고 날짜 문서를 링크한다.
3. 커밋했으면 커밋 해시를 오늘 문서에 적는다.

## 쓸 때 지키는 것

- **사실만 적는다.** 직접 돌려서 확인한 것만 "확인함"이라고 쓴다. 코드를 읽기만 했으면
  "코드만 읽음, 실행 안 함"이라고 적는다. 이게 이 체계의 전부다 — 틀린 인수인계는
  인수인계가 없는 것보다 나쁘다.
- **정본을 여기에 복사하지 않는다.** 아키텍처·계약·실측값의 정본은 `docs/` 에 있다
  ([`docs/SIM2REAL_ROADMAP.md`](../docs/SIM2REAL_ROADMAP.md),
  [`docs/SUPERDEX_POC_PLAN.md`](../docs/SUPERDEX_POC_PLAN.md),
  [`docs/RL_POLICY_REDESIGN.md`](../docs/RL_POLICY_REDESIGN.md)).
  여기에는 **"오늘 뭘 했고 다음에 뭘 할지"** 만 쓰고 근거는 정본 문서를 링크한다.
  정본에 들어갈 내용을 여기에 쓰면 정본이 둘이 되어 곧 서로 어긋난다.
- **날짜는 `2026-09-16` 처럼 전부 적는다.** "어제", "지난주" 는 나중에 읽으면 뜻을 잃는다.
- **명령은 복붙되게 적는다.** 어느 셸에서 어느 폴더에서 도는지, 가상환경을 켜야 하는지까지
  (원칙 3). `superdex/` 작업은 `superdex/.venv/`(파이썬 3.12), 나머지는 파이썬 3.10.11 이다.
- **한 파일 = 하루.** 같은 날 대화가 여러 번 열리면 같은 파일에 `## 세션 2` 로 이어 붙인다.

## 날짜 문서 틀

`claudeDocs/daily/YYYY-MM-DD.md` 를 새로 만들 때 아래를 복사해서 채운다.

```markdown
# 2026-MM-DD

이어받는 세션은 이 파일 맨 위 "현재 상태"와 맨 아래 "다음에 할 일"만 읽어도 된다.

## 현재 상태 (한 문단)

<지금 프로젝트가 어디에 있는지. 브랜치, 무엇이 돌아가고 무엇이 안 돌아가는지.>

## 세션 1

### 한 일

- <무엇을 왜 고쳤는지. 파일 경로와 함께.>

### 돌려본 것과 결과

| 명령 | 결과 | 판정 |
|---|---|---|
| `...` | <숫자나 로그 한 줄> | 통과 / 실패 / 미검증 |

### 사용자가 결정한 것

- <승인/보류/변경. 없으면 "없음".>

### 막힌 것

- <무엇이 왜 막혔는지. 없으면 "없음".>

### 커밋

- `<해시>` <제목>  ← 커밋 안 했으면 "커밋 안 함, 작업 트리에만 있음"이라고 적는다

## 다음에 할 일

1. <가장 먼저 할 것. 왜 이게 먼저인지 한 줄.>
2. <그다음>

## 이어받는 사람이 밟을 함정

- <있으면 적는다. 없으면 이 절을 지운다.>
```
