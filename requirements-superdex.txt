ray[rllib]

# ⚠️ torch는 여기에 넣지 않는다. ray[rllib]은 torch를 끌어오지 않고, PyPI 기본
#    Windows wheel은 CPU 전용이다. 두 작업 머신 모두 CUDA GPU로 learner를 돌릴 계획이므로
#    (회사 RTX 2080 8 GB — Turing이라 **bf16 불가**, 집 RTX 4070 Ti 12 GB)
#    CUDA wheel을 별도 인덱스에서 먼저 설치한다:
#      pip install torch --index-url https://download.pytorch.org/whl/cu124
#    설치 후 `python -c "import torch; print(torch.cuda.is_available())"`가 True여야 한다.
#    False면 learner를 GPU로 못 쓴다 — CPU로 돌려도 게이트 진행은 가능하다.
#    정확한 CUDA 태그(cu124 등)는 게이트 0에서 확인해 이 주석을 정정할 것.

# ONNX 내보내기·검증 (게이트 1의 3자 파리티 테스트).
# RLlib 새 API 스택은 ONNX export를 지원하지 않아(ray#45526) torch.onnx.export로
# 래퍼 nn.Module을 직접 내보낸다 — docs/SUPERDEX_POC_PLAN.md §5 게이트 1.
onnx
onnxruntime
