## 0. 최종 목표와 강화학습의 역할

> **손목에 달린 비전 카메라(eye-in-hand)로 공·큐브·원통 등 다양한 물체를 인식하면,
> UR16e + DG-5F-M이 스스로 움직여 관측한 형상에 맞는 파지점과 손 자세를 찾아내고
> 물체를 안정적으로 파지한다.**

**손잡이나 미리 등록된 물체 종류를 파지의 전제 조건으로 두지 않는다.** 여기서 인식은
물체를 배경에서 구분하고, 같은 개체를 추적하며, 파지에 필요한 위치·크기·표면을 추정하는
것을 뜻한다. “공”, “큐브”라는 이름을 맞히는 분류는 보조 정보다. 이름을 모르는 물체도
형상이 충분히 관측되고 로봇의 작업 범위 안에 있으면 파지를 시도하는 것이 목표다.

강화학습 목표는 **불완전한 손목 비전과 로봇 피드백을 이용해, 제한 시간 안에 지정 물체의
안정 파지 성공 확률을 높이는 팔·손 폐루프 정책을 학습하는 것**이다. 여기서 폐루프란
움직인 뒤 다시 관측하여 다음 움직임과 손의 닫힘을 수정한다는 뜻이다.

물체 검출·추적·형상 추정과 선택적인 분류는 별도 인식 모듈이 담당한다. RL은 그 결과를 받아 **더 잘 보이는
시점으로 이동할지, 어느 파지 후보를 시도할지, 어떤 자세로 접근하고 손을 닫을지,
접촉 이후 각 관절을 어떻게 보정해 유지하거나 재시도할지**를 배운다. 후보 생성기가 준 점에 도달하는 것만으로
완료하지 않으며, 실제 파지 결과가 후보 선택과 운동 제어의 공통 학습 신호가 된다.

### 0-1. 검증 가능한 요구사항

| ID | 요구사항 | 충족 증거 |
|---|---|---|
| R1 | 물체 정보는 손목 카메라에서 온다 | 배포 정책의 입력·행동 마스크·단계 전환에 시뮬레이터 물체 정답 정보가 없음. 실제 카메라 추정기를 연결한 평가 통과 |
| R2 | 이름을 몰라도 인식한 타깃을 일관되게 추적한다 | 클래스 미등록 물체도 형상·위치로 파지 가능. 방해물과 같은 종류의 다른 개체가 있어도 선택한 타깃을 유지하며 오파지를 별도 집계 |
| R3 | 움직여 파지점을 찾는다 | 초기 시야로는 부족한 장면에서 재관측 후 후보를 생성·선택. 최종 후보는 관측 형상에서 생성하며, 고정 오프셋 기준선보다 탐색 조건에서 개선 |
| R4 | 팔과 손이 다양한 형상에 맞게 함께 움직인다 | 공·큐브·원통·비정형 물체에서 접근 방향·손 관절별 자세을 조절. top-down 이외의 접근이 필요한 조건도 평가 |
| R5 | 물체를 안정적으로 파지한다 | 지지면에서 분리해 유지하고 정해진 외란을 견딤. 시험 전체에서 낙하·과도한 미끄럼·물체별 자세 제한 위반이 없음 |
| R6 | 인식 소실·접촉 실패에 대응한다 | 짧은 가림은 기억·피드백으로 대응하고, 불확실성이 커지면 정지·재관측·제한된 재시도로 전환. 확인 불가능한 상태를 성공으로 보고하지 않음 |

### 0-2. 이번 목표의 작업 범위

- 베이스는 정지하고 UR16e와 DG-5F-M 오른손이 작업한다. AMR 주행·운반·지정 위치 배치는 후속 과제다.
- 기본 학습 대상은 작업면 위의 **공(구형)·큐브·직육면체·원통·비정형 강체**다. 손잡이형은 다양한 형상 중 하나로 추가할 수 있으며 필수 대상이나 최종 목표가 아니다.
- 물체 종류 목록은 지원 대상을 제한하는 목록이 아니라 학습·평가 예시다. 크기·질량·개구폭·관측 품질이 검증된 작업 범위 안에서, 학습하지 않은 물체로의 일반화를 목표로 한다. 변형이 큰 공이나 연성 물체의 재질·변형 대응은 강체 기준선 이후 확장한다.
- 에피소드는 **첫 타깃 식별이 성립한 시점**부터 시작한다. 시작부터 아무것도 보이지 않는 전역 탐색은 별도 과제이며, 식별 이후의 가림과 시야 이탈은 이번 범위다.
- 단일 물체에서는 유효한 검출 개체를 타깃으로 고정한다. 다중 물체에서는 상위 태스크의 개체 지정이나 사전에 정한 선택 규칙으로 검출 개체 하나를 고정한다. 클래스 지정은 선택 사항이며, 등록된 클래스가 아니라는 이유만으로 제외하지 않는다. RL에 정답 물체의 시뮬레이터 ID를 주지 않는다.
- 고정 외부 카메라는 정책 입력의 필수 장비가 아니다. 독립 평가용 계측에는 사용할 수 있다.
- FOUP 같은 특정 제품의 취급 요구는 별도 응용 조건이다. 기본 정책은 제품별 손잡이 위치나 CAD 등록 없이 관측 형상으로 파지하며, 특정 제품의 성공을 이번 목표의 필수 완료 조건으로 두지 않는다.

## 1. 현행 설계에서 바꿔야 할 점

2026-09-07 저장소 코드와 설정을 대조했다. 현행은 `DG5FPicknPlace`, 관찰 57개·연속 행동 7개다.
GT(ground truth)는 시뮬레이터가 직접 알고 있는 물체 자세·접촉 등의 정답 상태를 뜻한다.
근거는 [Agent](../unity/Assets/MLAgents/picknplace/Runtime/Dg5fPicknPlaceAgent.cs),
[Spec](../unity/Assets/MLAgents/picknplace/Runtime/Dg5fPicknPlaceSpec.cs),
[씬 빌더](../unity/Assets/MLAgents/picknplace/Editor/PicknPlaceTrainingSceneBuilder.cs)다.

| 현행 구조 | 새 목표와의 차이 | 변경 방향 |
|---|---|---|
| 관찰 13..37에서 물체 위치·속도·상승높이·손끝 상대위치를 GT로 계산 | 실물 카메라의 오차·가림·지연을 거치지 않음 | 추정기 인터페이스로 교체. 이후의 파생 상태까지 출처 감사 |
| `GraspTargetHeightOffset = 0.040f`와 고정 팜 파지점 | 접근 목표가 미리 정해짐 | 관측 형상에 따른 복수의 파지 자세와 명시적 선택 |
| 직육면체 1종 중심의 학습 | 개체 식별·형상별 후보 선택 능력을 검증하기 어려움 | 복수 형상·복수 개체·방해물·미학습 형상 평가 |
| `_closure` 1개로 20관절을 open↔`RightFistDeg` 보간 | 물체에 맞춘 손 모양 조절 범위가 좁음 | 손 20관절 목표각을 각각 출력. 1/3그룹은 비교 기준선으로만 유지 |
| top-down 정렬·자세 항 | 접근 방향을 한 종류에 편향시킴 | 선택한 파지 자세 기준 접근, 물체별 자세 제약 분리 |
| 최종 단계에서 10 cm 상승, 속도 ≤0.50 m/s, 0.50초 유지 | 장시간 유지·미끄럼·외란 내성 검증이 부족함 | 정적 유지와 동적 외란을 포함한 성공 판정 |
| 자세·접촉·진행도 관련 보상이 여러 곳에 누적 | 비용 규모와 보상 악용을 추적하기 어려움 | 종료 보상·진행 셰이핑·운동 비용으로 명세 통합 |

### 기존 문서의 판단 중 바로잡는 부분

1. **물체 중력은 이미 켜져 있다.** 씬 빌더의 물체 Rigidbody는 `useGravity = true`이며,
   Agent는 리셋 때만 잠시 끈 뒤 물리 시뮬레이션 시작 시 다시 켠다. 로봇 링크의 중력 OFF는
   로드맵 §6에서 UR 내부 중력 보상을 근사하려는 선택으로 설명한다.
   안정 파지를 위해 모든 링크의 중력을 일괄 ON으로 바꿀 필요는 없다. 물체 하중·접촉·마찰이
   실제로 작용하는지와 팔의 하중 추종 응답이 타당한지를 검증해야 한다.
2. **접촉 센서의 존재와 정책 입력 연결은 별개다.** 로드맵은 SDK 핑거팁 센서 API를 기록하지만,
   현행 실물 브리지는 관절·전류·오류 데이터를 수신한다. 핑거팁 채널 수·단위·주기·임계값과
   팜 센서 유무를 확인하기 전에는 “실물 접촉 6칸 확보 완료”로 간주하지 않는다.
3. **카메라 기반 속도·상승량 추정은 원리적으로 불가능한 정보가 아니다.** 추적 이력과 시각을
   맞춘 FK로 추정할 수 있다. 새 기본 관찰에서는 신뢰도가 검증되지 않은 값을 제외하고,
   GT 직접 관찰을 금지한다. 손끝 상대위치의 중복 표현도 노이즈를 자동으로 15배 만들지는 않는다.
4. **외란 통과가 모든 자세 요구를 보장하지 않는다.** 기울어진 물체도 안정적으로 잡힐 수 있다.
   직립 유지나 특정 접촉 부위 제한은 물체별 요구로 따로 둔다.
5. **가상 추정기와 실물 추정기의 형식이 같다고 분포까지 같아지지는 않는다.** 가상 추정기만으로
   학습한 성과와 실제 이미지 기반 평가 성과를 구분한다.

### 1-1. 자체 리뷰 결과와 이번 결정

**다양한 물체를 잡는 데 항상 손 20자유도가 필수인 것은 아니다.** 제한된 물체는 단순한 손
표현으로도 다룰 수 있다. 그러나 이 문서의 목표는 미학습 형상과 개별 손가락의 접촉 보정까지
포함하므로, 3그룹 보간을 최종 구조로 고정할 근거가 부족했다. 이번 설계에서는 **손 20관절의
개별 위치 명령을 정책 출력으로 채택**하고, 그룹 제어는 난이도·성능 비교에만 사용한다.

| 중요도 | 발견한 문제 | 판단·수정 |
|---|---|---|
| 높음 | 손 실제각20을 관찰하면서 출력은 그룹3에 묶음 | 관찰이 상세해도 행동 자유도가 생기지는 않음. 엄지 대향·벌림·마디 굽힘을 각각 보정하는 act26 계약으로 변경 |
| 높음 | 팔 후보 위치·방향·개구폭만으로 손가락별 접촉 지점을 충분히 표현한다고 가정 | 손끝 주변의 관측 표면 위치·법선·거리·유효성40 추가. 모든 형상 표현이 충분하다는 주장은 계속 보류 |
| 높음 | 손 개별 명령각·속도와 접촉 시 목표 누적 제한 누락 | 실제각20·속도20·명령각20을 관찰하고, 관절별 속도·추종 오차·자기충돌 제한 명시 |
| 높음 | 시야에 따라 달라지는 관측 표면 중심을 5 mm 미끄럼 기준으로 재사용할 여지 | 접근용 중심과 동일 물체에 고정된 추적 기준점을 분리. 비교 가능한 기준점이 없으면 유지 증거는 무효 |
| 높음 | 26개 행동과 후보 선택을 처음부터 동시에 PPO로 탐색하는 학습 부담 | 계약은 처음부터 고정하고, 손 시범 초기화·접촉 근처 학습 → 팔/손 공동 제어 → 후보 선택·재관측 순으로 확장 |
| 중간 | 손 행동이 3→20개가 되면 운동 비용 합계가 커짐 | 팔6·손20 각각의 평균 정규화 비용으로 계산하여 §6의 전체 예산 유지 |
| 미해결 | 촉각 채널·관절 한계·지연·5 mm 계측 능력은 실측 전 | 슬롯·기능을 명세한 것과 실물 입력이 확보된 것을 구분. 구현/실측 게이트로 유지 |

DG-5F-M의 20관절 독립 구동은 [제조사 제품 설명](https://www.tesollo.com/products/grippers/dg-5f-m)에
명시되어 있다. 저장소의 [실물 브리지](../vision/dg5f/dg5f_sdk_bridge.py)에도 `MoveServoJoint`
20채널 경로가 있다. 반면 현행 Agent의 `ApplyGripTargets()`는 이 20개 목표를 단일 `_closure`
보간으로 만든다. **하드웨어의 20채널 명령 경로를 RL 정책에서도 활용하도록 바꾸는 설계**다.
이는 이번에 실물 20관절 동시 제어를 재시험했다는 뜻은 아니다.

## 2. 시스템 역할과 정보 경계

```text
손목 RGB/RGB-D + 촬영 시각 + 로봇 피드백
    ↓
검출·개체 추적·형상/자세 추정 → 관측 지도·파지 후보·불확실성
    ↓
기억을 가진 PPO 정책
    ├─ 팔을 움직여 재관측 / 후보 선택·변경
    └─ 팔 6축 + 손 20관절 폐루프 제어
    ↓
관절·속도·충돌·통신 상태 제한 → RTDE 팔 명령 / SDK 손 명령
    ↑                                      ↓
관측·접촉에 따른 실행 단계 관리 ← 실제 관절·손 센서·새 카메라 프레임

학습/평가 전용: 물체 GT·접촉 상대 ID·실제 미끄럼 → 보상·정답 평가
```

| 구성요소 | 책임 | 해서는 안 되는 일 |
|---|---|---|
| 인식·후보 생성기 | 타깃 추적, 관측 형상 복원, 복수 후보와 불확실성 제공 | GT 파지 정답을 실물 입력인 것처럼 제공 |
| RL 정책 | 관측 이력에 따라 후보와 팔·손 움직임 선택 | 처음 검출한 자세로 끝까지 개루프 실행 |
| 실행 단계 관리자 | 관측 가능한 조건으로 접근·파지·검증·복구 단계를 관리 | GT 접촉 상대나 GT 리프트 높이를 이용해 배포 정책의 단계를 바꿈 |
| 명령 제한 계층 | 관절·속도·작업영역·알려진 충돌·통신 이상 제한 | 작은 충돌 벌점만으로 실물 제한을 대체 |
| 학습 보상·평가기 | GT로 성공·오파지·낙하 등을 정확히 채점 | 보상용 GT를 관찰·행동 마스크·추론 상태에 유출 |

시뮬 학습 초기에는 GT에 오차를 적용하는 **가상 추정기**를 사용한다. 단, 손목 카메라의
시야·측정 거리·손가락 가림을 통과한 관측만 출력하고, 완전히 가려진 물체의 새 자세나 표면을
계속 알려주지 않는다. 배포 전에는 **시뮬 카메라 영상 → 실제 인식 알고리즘 → 동일 인터페이스**와
실제 손목 영상으로 검증한다. 실제 인식기의 시야 의존 오류를 재현하지 못하면 R1·R3 검증은 미완료다.

시뮬의 정책용 접촉 신호도 실물과 같은 의미여야 한다. “정답 타깃에 닿았을 때만 1”인
콜라이더 플래그는 비타깃 접촉을 구분하지 못하는 실물 촉각과 다르므로 그대로 이식하지 않는다.
접촉 상대의 정답 ID는 평가기에만 남기고, 정책에는 실물 센서가 구분할 수 있는 정보만 준다.

## 3. 정책이 학습할 행동 순서

아래 단계는 하나의 기억 기반 정책이 공유한다. 단계 관리자는 전환 조건을 제공하고,
관측 시점·접근 경로·후보·닫힘 조절은 정책이 결정한다. 전역 파지 성공의 정답 판정은 별도다.

| 단계 | 정책이 배울 행동 | 관측 기반 전환·복구 조건 |
|---|---|---|
| 재관측 | 타깃을 화면 안에 두고 시야·깊이·표면 관측을 개선하는 팔 움직임 | 유효 후보와 충분한 추정 품질 확보 → 접근. 제한 시간 내 확보 실패 → 실패 |
| 후보 선택·접근 | 파지 자세 선택, 손 펼침, 충돌을 피한 접근, 새 관측에 따른 수정 | 후보 주변에 도달하거나 접촉 감지 → 접촉 형성. 후보 소실·타깃 모호 → 재관측 |
| 접촉 형성 | 팔 미세 이동과 손 20관절의 굽힘·벌림·대향 조절로 지지 접촉 만들기 | 센서·실제 손 자세에 따른 잠정 파지 증거 → 검증. 빈손 닫힘·접촉 불균형 → 제한된 재시도 |
| 파지 검증·유지 | 작은 리프트, 정적 유지, 검증 움직임 중 닫힘과 팔 자세 보정 | 검증 증거가 모두 확보되면 완료. 미끄럼 증가·과도한 힘·낙하 → 복구 또는 실패 |
| 복구 | 하중 지지 여부에 따라 정지·낮추기·접촉 해제·재관측 | 지지면에 안전하게 놓인 상태를 확인한 후 다시 접근. 복구 한도 초과 → 실패 |

설계 초기 예산은 **전체 30초, 재시도 최대 2회**로 둔다. 파지 실패 후 카운터와 시간은
초기화하지 않는다. 물체가 들려 있을 때 바로 손을 여는 행동은 허용하지 않고 먼저 지지 상태를
확보한다. 물체 낙하·위험 충돌은 해당 시도의 즉시 실패다.

짧은 가림에서는 마지막 관측의 시각·불확실성, 관절과 접촉 이력을 이용한다. 가림 허용 시간은
접촉 전후로 따로 정한다. 접촉 전에는 낡은 추정으로 계속 돌진하지 않으며, 접촉 후에도
기억만으로 “안정 파지 확인”을 선언하지 않는다. 기억은 관측이 없는 사실을 측정값으로 바꾸지 않는다.

## 4. eye-in-hand 인식과 파지 후보의 계약

### 4-1. 좌표계와 시간

`T_A_B`는 B 좌표를 A 좌표로 변환한다. B=로봇 베이스, F=플랜지, C=카메라,
P=팜, O=물체, `t_c`=촬영 시각, `t`=현재 제어 시각으로 정의한다.

```text
T_B_O(t_c) = T_B_F(q(t_c)) · T_F_C · T_C_O(t_c)
추정 T_P_O(t) = inverse(T_B_P(q(t))) · 추적기가 예측한 T_B_O(t)
```

카메라 내부 보정과 **카메라↔플랜지 hand-eye 보정**이 필요하다. 움직이는 손목 카메라의
베이스 변환을 고정된 `T_B_C` 하나로 처리하지 않는다. 촬영 시각의 FK는 시간 정렬된 관절
이력으로 구하고, 전송 지연을 현재 팔 자세로 덮어쓰지 않는다. 좌표 축·회전 방향·m/rad와
Unity/브리지 경계의 단위 변환을 인터페이스에 명시한다.

RGB-D이면 깊이 유효성과 측정 범위를 검사한다. 단안 RGB로 시작할 때는 알려진 크기·모델·
마커 또는 별도 검증된 거리 추정 방법이 필요하다. 2D 박스와 클래스만으로 미터 단위 파지점을
얻었다고 가정하지 않는다. 마커를 쓰는 초기 검증과 마커 없는 최종 물체 식별 평가는 분리한다.

### 4-2. 인식 출력

| 필드 묶음 | 필수 내용 | 의미 |
|---|---|---|
| 타깃 식별 | 추적 ID, 타깃 조건 일치도, 추적 유효성, 선택적 클래스 확률·unknown 표시 | 추적 ID는 인식기가 생성. 클래스 미등록도 유효 타깃이며 원시 숫자 ID 자체를 연속 특징으로 쓰지 않음 |
| 위치·형상 | 추정 위치, 크기, 관측 표면/부분 지도, 추정 가능한 회전과 유효성 | 물체 전체의 6D 자세나 CAD 모델을 필수로 요구하지 않음. 대칭 물체의 회전 모호성과 가려진 부분을 표시 |
| 품질·시간 | 촬영·수신 시각, 마지막 유효 관측 나이, 위치·회전 불확실성 | 검출 점수와 자세 정확도를 같은 값으로 취급하지 않음 |
| 시야 | 화면상 타깃 중심·면적, 깊이 유효 비율, 관측 표면 비율 | 정책이 시점을 개선할 근거. GT 전체 표면을 기준으로 계산하지 않음 |
| 주변 환경 | 작업면 추정, 비타깃 형상·위치·불확실성, 미관측 영역 | 최근접 장애물 한 점만으로 팔 전체의 충돌을 판단하지 않음 |
| 후보 | 후보 ID, 팜 목표 자세, 접근 방향·거리, 개구폭, 품질·불확실성, 유효 마스크 | 품질 점수는 생성기의 추정값이며 정답 성공 확률이 아님 |

미검출 때에는 마지막 추정에 나이를 누적하고 불확실성을 증가시킨다. 유효하지 않은 수치의
패딩과 마스크 규약을 정하며, 가려졌다는 이유로 물체를 원점에 있다고 해석하지 않는다.
추적 ID가 바뀌면 타깃 동일성을 재확인하고, 이전 후보·기억을 새 물체에 무조건 재사용하지 않는다.

### 4-3. “파지점을 찾는다”의 구체적 의미

파지점은 3D 점 하나가 아니라 **팜의 위치·방향, 접근 경로의 마지막 구간, 필요한 개구폭과
허용 접촉 영역**의 묶음이다. 같은 위치도 접근 방향과 손 모양에 따라 결과가 달라진다.

| 수준 | 후보 생성 방법 | 성과 해석 |
|---|---|---|
| 초기 운동 기준선 | 물체 로컬 주석을 추정 자세로 변환 | S0의 선택적 진단·비교용. 기본 학습과 최종 파지 경로의 필수 입력으로 쓰지 않음 |
| 새 목표의 기본안 | 손목 깊이/복원 표면에서 패치·법선·대향 표면·개구폭을 이용해 다수의 팜 자세 제안 | 재관측으로 후보가 생기고 바뀌며, 정책이 실제 파지 결과로 선택을 학습 |
| 알려진 모델 보조 | 특정 응용에서만 모델의 허용 접촉 영역을 후보 필터로 사용 | 공·큐브 등 기본 파지에 필수가 아님. 관측 기반 후보와 결과를 구분하고 GT 성공 라벨·정답 점수는 금지 |

후보 생성기는 “공이면 이 좌표”, “큐브이면 윗면 중앙” 같은 클래스별 정답 규칙 대신
**현재 보이는 표면·곡률·두께·접근 여유와 손의 개구폭**을 이용한다. 물체 전체의 기준
회전축이 모호해도 카메라/팜 좌표에서 후보의 접근 방향과 팜 자세를 정의할 수 있도록 한다.
아래는 학습시킬 차이이며, 클래스에 따라 반드시 실행할 고정 동작표가 아니다.

| 형상 예시 | 정책이 탐색할 차이 | 평가에서 확인할 실패 |
|---|---|---|
| 공·구형 물체 | 곡면을 감싸는 접촉 배치, 접근 중 굴러감에 따른 재추적, 손가락별 닫힘 | 손으로 밀어 굴려 버림, 접촉 중 빠져나감, 들어 올린 뒤 이탈 |
| 큐브·직육면체 | 면·모서리·대향 표면 중 접근 가능한 영역과 개구폭 | 모서리만 걸침, 물체 밀어냄, 빈손 닫힘 |
| 원통 | 지름·길이·놓인 방향에 따른 감싸기와 접근 방향 | 축 방향 빠짐, 옆으로 구름, 회전 중 접촉 소실 |
| 비정형·새로운 물체 | 부분 관측에서 잡을 두께와 지지 접촉을 찾아 재관측 | 보이지 않는 면을 잘못 추정, 유효 후보 누락, 불균형한 접촉 |
| 손잡이형 물체(선택) | 손잡이와 본체 중 실제 접근·파지 가능한 영역 선택 | 손잡이를 고정 정답으로 가정해 본체의 유효 파지를 놓침 |

관측 형상으로 만든 후보도 실행 가능한 정답은 아니다. 손의 개구폭·실측 가동범위·접근 구간
충돌로 불가능한 후보를 걸러내고, 팔 전체의 도달성과 충돌은 제어 경로에서 추가 검사한다.
이 필터 또한 실물에서 얻을 수 있는 형상·FK·관측 지도만 사용한다.

초기 최대 후보 수는 **M=8**로 제안한다. 부족한 슬롯은 패딩하고 마스크한다. 후보 ID와 슬롯
대응을 추적하여 프레임마다 점수 정렬로 선택 의미가 뒤바뀌지 않게 한다. 새로운 표면을 보아
후보가 보충될 수 있으며, 후보가 0개면 재관측한다. 재시도 때에는 실패 후보의 이력을 유지한다.
후보 생성기의 유효 파지 후보 포함률도 별도로 측정한다. 후보가 없으면 선택 정책만 튜닝해서
문제가 해결되지는 않는다.

## 5. 관찰·기억·행동 재설계

### 5-1. 관찰 v3 — 손 20관절 제어를 위한 366개 계약

**새 기본 계약은 `obs_v3_366`: 한 결정 시점에 float 366개다.** 아래는 구현할 슬롯의
제안 명세이며 현재 코드의 `ObservationSize = 57`을 변경한 것은 아니다. 이전 `obs_v2_272`는
3그룹 제어안의 이력이며 이번 명세로 대체한다. 센서가 없어도 실행 중 크기를 바꾸지 않고 정해진 마스크로
표현한다. 단, 실제 센서 확보·분포 검증 전에는 이 계약의 실물 적용을 완료한 것으로 보지 않는다.

카메라 영상·전체 점군을 이 벡터에 직접 넣지 않는다. 인식·후보 생성기가 관측 표면을 처리하고,
정책에는 **타깃의 위치·관측 범위·품질, 파지 자세 후보 8개, 주변 여유거리와 손끝별 표면 정보**를 넣는다.
클래스 이름, 물체 전체 회전6, 미정의 형상 임베딩, 보정되지 않은 접촉력은 기본 입력에서 뺀다.
공·큐브·원통의 차이는 관측 크기, 후보의 위치·방향·개구폭과 손끝 주변 표면을 통해 반영한다. 이 요약으로
부족한 비정형 물체는 형상 인코더를 추가하는 후속 계약으로 다루며, 366개만으로 모든 형상을
충분히 표현한다고 가정하지 않는다.

##### G. 손끝 주변 관측 표면: `326..365`

손가락 `j=0..4`(엄지→소지)의 시작은 `g=326+8j`다. `g+0..2`는 손끝에서 해당 관측 표면점까지의
벡터3(팜 축, m ÷0.20), `g+3..5`는 표면 법선3(팜 축), `g+6`은 손끝-표면 거리(m ÷0.20),
`g+7`은 유효성0/1이다. 다섯 범위는 **326..333, 334..341, 342..349, 350..357, 358..365**다.

선택 후보의 접근 영역 안에서 각 실제 손끝 FK 주변의 관측 표면 패치를 찾고, 시간적으로 대응되는
패치를 우선 유지한다. 처음에는 가장 가까운 유효 패치를 쓰되, 이는 **보이는 주변 형상**이며
정답 접촉점·보장된 대향 파지를 뜻하지 않는다. 선택 후보가 없거나 패치의 시각·법선·거리
불확실성이 허용 범위를 넘으면 해당 8칸을 마스킹한다. 법선의 앞뒤는 관측 방향에 맞춰 일관되게
정하고, 가려진 뒷면의 GT 법선으로 보충하지 않는다. 순간적으로 가장 가까운 표면이 바뀌는
것을 실제 미끄럼으로 해석하지 않는다.

이 입력은 “검지만 조금 굽히기”, “엄지 대향을 바꾸기” 같은 관절별 조절의 기하 근거다.
다섯 표면점만으로 모든 접촉 배치를 표현하지는 못하므로, G블록 제거 비교와 비정형 물체
평가를 통해 한계를 확인한다. 부족하면 다중 패치/점군 인코더를 새 계약으로 추가한다.

#### 5-1-6. 단위·결측·센서 계약

- 위 거리·시간·불확실성 스케일은 **초기 설계값**이다. 위치·부호 있는 거리·명령은 −1..1,
  크기·확률·진행·나이는 0..1로 클립한다. 일반 나이는 `min(ageSeconds/1.0, 1)`로 표현한다.
  클립 범위를 벗어나는 빈도가 높으면 범위를 바꾸고 계약 버전을 올린다.
- 초기 만료시간 제안은 팔·손 실제각/촉각 0.20초, 타깃·후보·영상 특징 0.50초다.
  실측 주기·지연에 맞춰 학습 전에 확정한다. 나이의 정규화 상한과 유효성 만료시간은 다른 값이다.
  관측 지도에서 계산한 여유거리도 사용 표면의 만료·불확실성을 반영해 마스크한다.
- 결측 수치는 0, 유효 마스크는 0, 한 번도 받은 적 없는 관측의 나이는 1로 채운다. 단, 모르는
  위치/방향 불확실성은 1로 채운다. 첫 관측 이후의 나이는 실제 경과시간을 누적한다.
  **접촉값0·유효1은 “안 닿음”, 접촉값0·유효0은 “모름”**이다. 원시 NaN/∞는 정책에 넣지 않는다.
- 짧은 가림에서 `target_visible=0`이어도 이력 기반 중심 추정은 만료 전까지 `center_valid=1`일
  수 있다. 나이와 불확실성을 늘리고, 현재 FK로 팜 기준 표현을 갱신한다. 실제 새 표면 관측이
  없으면 관측 시각·후보 나이를 리셋하지 않는다.
- 팜 센서와 아날로그 접촉력/전류는 이 기본 계약에 포함하지 않는다. 손끝5채널도 **확보 가정의
  슬롯 예약**이다. 미확보 채널을 GT 접촉으로 채워 실물 입력인 척하지 않는다. 실물에 일부
  채널만 있다면 같은 채널 마스크로 학습·평가하고, 이력 중 누락도 학습에 반영한다.
- 손끝 접촉 피드백이 전혀 없는 구성은 접촉 이후 정책의 별도 검증이 필요하다. 모든 마스크를
  0으로 만들었다는 이유로 촉각 기반 파지 목표를 달성한 것으로 간주하지 않는다. 팔·손 실제각
  피드백 소실은 제한 계층에서 신규 접근/닫힘 명령을 중지하고, 파지 중에는 하중 유지 절차를 따른다.
- 후보 M=8과 각 채널 순서는 계약 상수다. 단순한 물체도 후보 슬롯을 줄이지 않는다.
  모델 메타데이터에 `obs_v3_366`, 관절 순서, 스케일, 센서 프로파일을 함께 저장한다.

#### 5-1-7. 정책에 전달되는 입력과 기억

```text
현재 상태 벡터: obs_v3_366 [batch, 366]
후보 행동 마스크: [batch, 9] — 후보 유효성 + 실행 단계에서 계산하는 별도 입력
정책 기억: recurrent state — 크기·입출력 이름은 선택한 모델 설정/ONNX 계약으로 확정
출력: 팔6·손20 연속 행동 + 후보 선택 이산 행동 + 다음 기억 상태
```

366은 **한 시점의 상태 벡터 크기**다. 행동 마스크와 recurrent state까지 포함한 ONNX 전체
입력 크기라고 표현하지 않는다. 이산 선택지0은 항상 활성화하고, `i+1`은 후보 `i`의 유효성과
단계 조건으로 마스킹한다. 행동 마스크에 GT 도달 가능성·GT 접촉 상대를 사용하지 않는다.

관측 이력을 기억하는 recurrent PPO를 기본안으로 제안한다. 프레임 스택 기준선은 예를 들어
4프레임이면 `366×4=1464`개이며 다른 입력 계약으로 구분한다. 기억 길이는 허용 가림 시간에
맞춰 검증한다. 실물에서도 기억 상태를 유지하고, 에피소드 시작·타깃 변경·통신 재시작에서
초기화한다. 후보와 접촉의 시간 연속성을 잃지 않도록 학습과 실물의 시각·리셋 규약을 맞춘다.

### 5-2. 행동 v3 — 팔6 + 손20의 연속 행동26

**새 연속 행동은 `act_v3_26`이며, 손의 각 관절 목표를 독립적으로 보정한다.** 별도로 후보
선택용 9개 선택지의 이산 분기1개를 둔다. 손 20개가 서로 무관하게 움직인다는 뜻은 아니다.
하나의 정책이 접촉과 물체 형상에 맞춰 20개 값을 함께 결정하되, 그룹 보간으로 묶지 않는다.

| 연속 행동 인덱스 | 개수 | 명령 대상·순서 |
|---|---:|---|
| `0..5` | 6 | UR16e 팔6 관절 목표각 델타, 기존 팔 관절 순서 |
| `6..9` | 4 | 엄지: `thumb_cmc`, `thumb_opp`, `thumb_mcp`, `thumb_ip` |
| `10..13` | 4 | 검지: `index_abd`, `index_mcp`, `index_pip`, `index_dip` |
| `14..17` | 4 | 중지: `middle_abd`, `middle_mcp`, `middle_pip`, `middle_dip` |
| `18..21` | 4 | 약지: `ring_abd`, `ring_mcp`, `ring_pip`, `ring_dip` |
| `22..25` | 4 | 소지: `pinky_cmc`, `pinky_lat`, `pinky_mcp`, `pinky_pip` |

손의 관찰·행동·SDK 목표 배열은 모두 같은 20채널 순서를 쓴다. 채널명은
[`dg5f_angles.py`](../vision/dg5f/dg5f_angles.py)의 `CHANNEL_NAMES`, 실물 대응·범위는
[`dg5f_sdk_bridge.py`](../vision/dg5f/dg5f_sdk_bridge.py)의 오른손 매핑을 대조한다.
사람 손 텔레옵의 좌우 미러·각도 재매핑을 RL 출력에 다시 적용하지 않는다. 이미 로봇 관절값을
출력하므로 부호·영점·단위 변환은 한 번만 한다. 범위는 코드의 임시 상한을 실측 완료값으로
오해하지 않고 시뮬/실물 공통 검증 범위로 확정한다.

이산 행동은 `0=현 선택 유지/미선택 유지`, `1..8=해당 유효 후보 선택`이다. 후보 변경은
재관측·접근 단계에서만 허용하고, 접촉 이후에는 잠근다. 선택지0은 항상 활성화한다.
ML-Agents의 혼합 행동·마스킹은 [공식 Agents 문서](https://unity-technologies.github.io/ml-agents/Learning-Environment-Design-Agents/)를
참고하되, 설치 버전과 ONNX 추론 경로의 지원은 구현 전 확인한다. 과거 act7·제안 act9와
호환되지 않으며, 출력 크기만 바꿔 과거 가중치를 바로 사용하지 않는다.

#### 5-2-1. 손 행동의 물리적 의미

```text
j = 0..19
u_j = clip(a_hand[j], -1, +1)
Δq_j = u_j × v_limit[j] × Δt
q_requested[j] = q_cmd_previous[j] + Δq_j
q_cmd_next[20] = Limit(q_requested[20], q_actual[20], qd_actual[20], geometry, feedback)
```

정책 내부 각도는 rad로 통일하고, 기존 브리지 deg 경계에서 변환한다. `v_limit[j]`는 관절별
검증 속도이며 모든 채널에 같은 임의 각도 델타를 주지 않는다. 0 행동은 이전 목표각 유지,
양/음 행동은 그 관절의 양/음 방향 이동이다. 모든 관절에서 양수가 “더 꽉 닫기”인 것은 아니다.
엄지 대향·벌림도 실제 부호 규약을 따른다.

팔도 관절 델타를 유지한다. 결정주기는 현행 10 Hz를 초기 비교값으로 두고, 하위 서보 주기·
보간·제한을 분리한다. §7 외란 구간에서는 팔 기준 궤적에 제한된 보정을 합성하고, 손20의
명령각 보정은 계속 동작한다. 실제 송신된 목표 델타를 관찰 `78..103`에 반영한다.

**이는 관절 위치 제어이며, 관절별 토크/접촉력 제어를 구현했다는 뜻이 아니다.** 하위
위치 서보가 실물 모터를 구동한다. 손끝 센서5개도 관절20개의 접촉력을 각각 알려주지는 않는다.

#### 5-2-2. 개별 제어에 필요한 제한과 피드백

- `Limit`는 관절 위치·속도·가속도, 손가락 간 자기충돌, 팔·환경 충돌을 함께 검사한다.
  SDK가 개별 각도를 받는다는 사실만으로 모든 20차원 조합이 실행 가능하지는 않다.
- 물체 때문에 실제 관절이 멈췄는데 목표각만 계속 누적되지 않도록 `q_cmd−q_actual`의 관절별
  허용 추종 오차를 제한한다. 이 제한과 속도·가속도 제한을 동시에 만족할 수 없으면 목표를
  갑자기 재설정하지 않고 이상 상태/유지 절차로 전환한다. 실제각으로 무조건 목표를 덮어써
  유지 중인 파지 하중을 잃게 만들지 않는다.
- 접촉했다고 손20개 전체를 동시에 정지시키지 않는다. 관측 가능한 접촉과 실제각·속도·추종
  오차로 어느 관절의 추가 움직임을 제한할지 판단하고 나머지는 필요한 보정을 허용한다.
  전류·오류 한계는 확보된 SDK 피드백으로 제한 계층에서 검사하되, 전류를 보정 없이 힘으로 환산하지 않는다.
- 기본 정책은 전류/토크를 직접 출력하지 않는다. 강체 접촉에서 관절별 힘 조절이 필요한지,
  현행 위치 모드의 추종 오차 제한만으로 충분한지는 S0 실측에서 확인한다.
- 학습 중 실제 적용한 명령과 원래 정책 출력을 각각 기록한다. PPO 학습의 행동·log probability는
  실제 샘플링한 정책 출력에 대응시키고, 제한 이후 값을 정책이 원래 출력한 값처럼 덮어쓰지 않는다.
- 독립 제어 검사는 관절별 작은 단독 명령의 매핑과 실제 응답부터 수행한다. 이어서 엄지
  대향+벌림, 서로 다른 손가락 굽힘, 마디별 굽힘의 조합에서 추종·충돌·파지 유지 여부를 확인한다.

### 5-3. 20관절 학습을 시작하는 방법

20관절 출력이 필요하다는 판단과, 26개 행동을 무작위 PPO로 처음부터 모두 발견하게 하는
선택은 별개다. **관찰366·연속 행동26 계약은 처음부터 고정하고, 학습하는 상황을 단계적으로
넓힌다.** 3그룹 네트워크를 최종 정책으로 고정한 뒤 관찰만 덧붙이는 방식은 쓰지 않는다.

1. S0에서 공·큐브·원통의 파지 가능한 손 자세와 짧은 접촉 궤적을 교시/스크립트로 확보한다.
   기존 주먹 자세는 예시 하나로만 사용한다. 저장할 것은 관측366, 행동26, 실제 적용 명령,
   시각·성공 결과이며, actor 입력은 이때도 관측 가능한 값으로 만든다.
2. 시범으로 **동일 act26 정책을 행동 모방 초기화**하고, 쉬운 후보·접촉 근처부터 PPO로
   학습한다. 초기에는 팔을 제한하거나 위치를 가까이 두어 손20개의 유효 조절부터 배운다.
   모든 관절의 출력 채널은 유지하고, 학습 범위·스케일은 단계의 환경 설정으로 기록한다.
3. 팔 접근 범위와 손의 관절별 보정 범위를 넓힌다. 후보 선택은 초기 한 개/쉬운 후보에서
   다중 후보로 확장하고, 이후 재관측·가림·재시도·외란을 도입한다.
4. 시범 의존 없이 성능이 유지되는지 확인한다. 시범과 다른 배치·크기·미학습 형상에서
   평가하고, 처음부터 학습한 act26 및 손1/3그룹 기준선과 비교한다.

시범을 활용한 초기화·보정은 고차원 조작의 탐색 부담을 줄이기 위한 선택이다.
[Residual RL from Demonstrations 연구](https://arxiv.org/abs/2106.08050)는 관련 선행 사례지만,
이 프로젝트의 DG-5F-M 성능을 보장하지 않는다. 본 기본안은 **직전 목표각에 대한 관절별 델타**다.
후속으로 시범/기저 정책의 출력에 residual을 더하는 방식을 택한다면, 그 기준 명령·모드도
actor가 알 수 있도록 별도 관찰 계약을 설계한다. 현재 366개에 숨겨진 기준 제어기를 추가하지 않는다.

## 6. 보상 목표와 보상 악용 방지

### 6-1. 목적함수

최종 선택 기준은 **정해진 작업 범위의 안정 파지 성공률**이다. 시간과 움직임은 같은 성공
조건을 만족하는 정책의 효율을 비교하는 보조 지표다. 충돌·관절 제한 등은 실행 제약으로
두고, 보상을 많이 받았다는 이유로 위반을 허용하지 않는다.

```text
r_t = R_terminal
    + λ · [γ Φ(b_(t+1)) − Φ(b_t)]
    − c_time · Δt − c_motion · Δt · normalized_motion_cost
```

`b_t`는 관측 이력에서 만든 추정 상태이며, 실행 단계·시간·선택 후보·관측 지도 이력을
포함한다. `Φ`는 [0,1] 범위의 진행 척도다. **재관측 품질, 선택 후보의 위치·방향 정렬,
접촉 형성, 지지면 분리·유지 증거**를 단계에 맞게 결합한다. 후보 점수·접촉 개수·손 닫힘이
커지는 것만으로 완료 상태에 도달하지 않게 한다.

할인율을 포함한 포텐셜 차분은 [Ng·Harada·Russell의 보상 변환 연구](https://people.eecs.berkeley.edu/~pabbeel/cs287-fa09/readings/NgHaradaRussell-shaping-ICML1999.pdf)를 따른다.
단순한 `Φ(next)−Φ(now)`나 양의 증가분만 보상하는 “신기록 보상”과 구분한다.
본 설계의 근사 기억 상태와 함수 근사 PPO에서 성능 향상이나 이론적 최적 정책 보존을
자동 보장한다고 주장하지 않는다.

### 6-2. 초기 보상 예산 제안

| 항목 | 초기값 | 지급 조건 |
|---|---:|---|
| 안정 파지 성공 | +10, 종료 시 1회 | §7의 정답 평가 조건 전부 통과 |
| 실패 | −2, 종료 시 1회 | 낙하·오파지·위험 충돌·제한 이탈·타임아웃·복구 소진. 사유는 별도 기록 |
| 진행 셰이핑 | λ=2, Φ∈[0,1] | 위 식의 할인 포텐셜 차분 |
| 시간 비용 | −0.02/초 | 30초 기준 총 절댓값 ≤0.6 |
| 운동 비용 | −0.02/초 × [0,1] | 팔6·손20의 평균 정규화 비용을 결합, 총 절댓값 ≤0.6 |

초기 비교값 `γ=0.995`, 10 Hz, 최대 300결정이면 마지막 성공 보상의 할인값은 약 2.2다.
지속 비용의 비할인 상한 1.2와 함께 검토한다. 이것만으로 학습 성공이 보장되지는 않으며,
정지·빈손 리프트·반복 접촉·늦은 실패 궤적과 실제 할인 수익을 비교해야 한다.
보상 크기나 결정주기를 바꾸면 이 예산도 다시 계산한다.
표의 값은 상대 예산이며, 학습기의 수치 안정성을 위해 모든 보상·비용에 공통 배율을 적용할 수
있다. 이때 일부 항만 바꾸지 않고 배율과 실제 투입값을 실험 설정에 함께 기록한다.

손 관절 수만큼 비용을 단순 합산하지 않는다. 각 관절의 명령 변화 비용을 [0,1]로 정규화한 뒤
`0.5×mean(팔6 비용) + 0.5×mean(손20 비용)`을 초기안으로 쓴다. 접촉 근방 움직임 비용을
포함하면 동일 [0,1] 범위 안의 가중 평균으로 결합한다. 이로써 3→20관절 확대가 에피소드
운동 비용 상한을 자동으로 키우지 않게 한다. 손끝-표면 근접은 접촉 보조 셰이핑일 뿐이며,
모든 손가락을 같은 패치에 모으거나 과도하게 누르면 이득이 생기는 별도 보상은 두지 않는다.

### 6-3. 반드시 막을 우회 행동

- 성공·실패·태스크 타임아웃 모두 terminal에서 `Φ=0`으로 처리한다. rollout 절단은 태스크
  종료와 구별해 bootstrap한다. 후보·단계 변경 시 포텐셜의 이전 값을 임의로 0으로 리셋하지 않는다.
- 물체를 계속 보거나 후보를 계속 바꾸는 행동에는 매 스텝의 별도 양의 보상을 주지 않는다.
  재관측은 유효 정보와 최종 파지에 기여해야 한다.
- 접촉·파지 확인 이벤트를 재시도마다 누적 지급하지 않는다. 빈손 닫힘·빈손 리프트는 성공이 아니다.
- 손과 작업면 사이에 끼우기, 방해물에 기대기, 물체를 고정 조인트로 붙이기는 안정 파지로 채점하지 않는다.
- 오식별·추정 실패로 정책의 잠정 파지 신뢰도가 높아져도 GT 정답 평가에서 실패하면 종료 성공 보상을 주지 않는다.
- 엄지 방향과 물체 기울기의 요구는 후보의 허용 접촉 영역·물체별 자세 제약으로 명시한다.
  외란 시험이 자동으로 이를 대신한다고 가정하지 않는다.
- 물체의 클래스 이름을 맞히거나 손잡이를 선택했다는 이유로 보너스를 주지 않는다. 동일한
  안정 파지 조건을 형상별로 평가하며, 공의 접근 중 구름은 재추적 대상이다. 구름 자체를
  무조건 전도 실패로 처리하지 않고 작업 범위 이탈·시간 초과·낙하와 구별한다.

## 7. “안정적으로 파지했다”의 성공 판정

### 7-1. 판정 절차

**정확한 타깃 → 접촉 형성 → 지지면 분리 → 정적 유지 → 제한된 외란 → 유지 확인**을 모두
통과해야 성공이다. 아래 수치는 실측 전의 평가 초안이며, 물체별 시험 프로파일로 고정한 뒤
사용한다. 학습 후 성공률에 맞춰 기준을 완화하지 않는다.

| 항목 | 초기 평가 기준 제안 | 판정 의미 |
|---|---|---|
| 타깃 | 지정한 물체 개체이며 비타깃 동시 파지 없음 | 클래스만 맞는 다른 물체는 실패 |
| 지지면 분리 | 5~10 cm 리프트 범위에서 물체와 지지면의 실제 비접촉 확인 | 손 높이만으로 판정하지 않음. 바닥·장애물 지지 금지 |
| 정적 유지 | 분리 후 2초 | 접촉과 상대 자세가 지속적으로 유지 |
| 외란 | 검증된 제한 내에서 방향·위상을 바꾼 시험 2초 | 크기·가속도·주파수·방향·지속시간을 결과와 함께 기록 |
| 미끄럼 | 기준 팜 상대 위치 대비 시험 중 최대 이동 ≤5 mm | 종료 순간만 비교하지 않음. 물체 크기·정밀도 요구에 따라 사전 확정 |
| 상대 회전 | 회전이 식별되고 유지가 요구되는 축에서 시험 중 최대 변화 ≤5° | 공의 임의 기준축 오차를 실패로 쓰지 않음. 회전 관측 가능성과 물체별 요구를 사전에 구분 |
| 절대 자세 | 물체별 허용 기울기·접촉 부위 제한 | 단순 블록에 불필요한 직립 조건을 강제하지 않음 |
| 하중·손 상태 | 낙하·과도한 압착·관절 제한 위반 없음 | 힘 기준은 보정된 센서 확보 시 물체별로 설정 |

미끄럼 기준 자세는 초기 접촉 정착이 끝난 검증 시작 시점의 `T_P_O`로 고정한다. 시험 도중
움직일 때마다 기준을 다시 잡지 않는다. 위치·회전 오차의 **전체 시험 구간 최대값**과 접촉
소실 시간을 기록하며, 허용 센서 디바운스와 실제 접촉 이탈을 구분한다.
무늬 없는 공의 실제 회전은 표면만으로 확인하기 어려우므로, 공은 중심의 상대 이동·접촉
유지·낙하·외란 내성을 기본 판정으로 둔다. 표면 미끄럼이나 회전 억제가 필요한 작업에서는
추가 계측으로 별도 판정한다. 공의 회전을 측정하지 않은 결과를 “표면 미끄럼 0”으로 보고하지 않는다.

### 7-2. 외란을 어떻게 줄 것인가

기본 시험은 팜의 기준 궤적에 제한된 움직임을 주어 관성 하중을 만드는 방식이다. 기준 궤적은
검증 단계 관리자가 제공하고, 정책의 팔 출력은 이 구간에서 제한된 보정으로 해석하며 손의
20관절 목표각 보정은 계속 허용한다. 관측에는 실제 실행 명령·피드백이 들어간다. 기준 궤적을 제거하거나
보정으로 상쇄해 정적 유지 시험처럼 통과할 수 없도록 **실제 인가된 움직임·가속도가 시험
프로파일을 충족했는지 평가기에서 확인**한다. 미달이면 외란 통과로 집계하지 않는다.

시뮬에서 물체에 힘·토크를 주는 시험은 추가 강건성 평가로 사용할 수 있다. 단, 실제 시험과
동등하다고 주장하지 않고 `SimWrenchTest`로 분리한다. 외란의 위상·방향은 보상 평가용 정답
정보로 정책에 미리 알려주지 않는다. 외란 강도는 물체 하중과 장비의 검증 범위 안에서 정하고,
실측 전 임의의 큰 충격값을 실물 명령으로 사용하지 않는다.

### 7-3. 실행 중 판단과 정답 평가의 구분

| 구분 | 사용할 수 있는 증거 | 제한 |
|---|---|---|
| 시뮬 학습·평가 | 물체 GT, 접촉 상대, 팜 상대 이동, 작업면 접촉, 인가 외란 | 보상·정답 평가 전용. actor 입력에 금지 |
| 실물 실행 | 카메라 추적, 실제 관절각, 확인된 촉각·전류, 추정된 지지면 분리 | 시야가 완전히 가리면 mm 단위 미끄럼을 직접 확인했다고 할 수 없음 |
| 실물 독립 평가 | 외부 영상/마커·계측기 등으로 타깃·분리·미끄럼·외란을 계측 | 정책에는 공급하지 않음. 계측 정밀도·누락률도 기록 |

실물 실행은 “접촉 확인”, “파지 유지 추정”, “안정 파지 검증 완료”를 구분한다. 완전 가림과
센서 한계로 성공 조건을 관측할 수 없다면 재관측하거나 **검증 불가**로 남긴다. 독립 계측에서
확인된 성공률과 로봇 자체 판정의 정확도도 따로 보고한다. 전류만으로 접촉력·손상 없음이
입증되었다고 간주하지 않는다.

## 8. 학습 커리큘럼과 승급 조건

Unity PhysX·ML-Agents·PPO를 유지한다. 알고리즘 교체보다 관찰 출처·후보 탐색·성공 정의를
먼저 바로잡는다. 초기 운동 학습에도 물체 중력·하중은 적용한다.

| 단계 | 환경·입력 | 배울 능력 | 승급 시 평가 |
|---|---|---|---|
| S0 물리·계약 검증 | 손20관절 단독/조합 응답, 교시·스크립트 파지, 시범 데이터, GT 진단 모드 | 관절 매핑·자기충돌·추종 오차 제한·물리적 파지 가능성 확인 | 제어·관측·하중 검사 통과. GT 진단 모드는 최종 성과에서 제외 |
| S1 기본 운동 | 동일 act26 정책의 시범 초기화, 접촉 근처·쉬운 후보1개에서 시작해 팔 접근 범위를 확장 | 손20관절의 접촉 형성·유지 → 팔/손 공동 접근·리프트·2초 유지 | 공·큐브·원통 각각의 미학습 배치별 정적 유지 성공률 |
| S2 능동 재관측 | 후보8개 선택으로 확장, 관측 표면·팔 움직임에 따른 가림·지연·드롭아웃 | 시야 개선·후보 선택/보충·기억·재시도 | 재관측 필요 조건의 성공률과 재관측 시간 |
| S3 식별·일반화 | 비정형 물체·새로운 크기/비율·동일 클래스 복수 개체·방해물, 클래스 정보 누락, 질량·마찰 변화 | 클래스에 의존하지 않는 개체 추적·관측 형상 기반 접근·손 조절 | 형상별·unknown 조건별 정적 유지 성공률과 오파지율 |
| S4 안정 파지 | 정적 유지 + 점진적 외란, 촉각·구동 오차 | 외란 중 유지·미끄럼 대응 | 최종 외란 프로파일에서 §7 성공률 |
| S5 실제 인식·실물 검증 | 렌더 영상과 실물 영상의 동일 추정기, 제한된 실물 작업 | 전체 인식·제어 연결 검증 | §9의 시뮬·실물 분리 평가 |

승급은 학습 스텝 수만으로 결정하지 않는다. 단계마다 분리된 평가 세트를 사용하고,
**아직 외란을 도입하지 않은 S1~S3에 외란 통과율을 승급 기준으로 쓰지 않는다.**
S1~S3의 종료 성공 보상은 해당 단계의 정적 유지 조건으로 지급하고 `StageSuccess`로 기록한다.
S4는 현재 커리큘럼 강도의 통과를 학습하되, §7의 최종 프로파일 통과만 `StableGraspSuccess`로
집계한다. 최종 성공 보상만 두어 초기 단계에서 양의 종료 보상이 불가능해지는 일을 피한다.
초기 승급안은 별도 검증 세트에서 해당 단계 성공률 90% 이상을 3회 연속 충족하는 것이다.
S1 이후에는 공·큐브·원통 각각에 기준을 적용하여, 큐브의 높은 성공률이 공의 실패를 가리지 않게 한다.
S3 이후에는 오파지율 1% 이하도 요구한다. 이 검증 세트는 §9의 최종 미사용 평가 세트와 분리한다.
낮은 오차에서 성공했던 조건을 일정 비율 재혼합하여 후속 단계에서 기본 운동을 잊지 않게 한다.
S0 불일치는 구현 오류·물리 설정·관찰/행동 표현 변화·전이 실패를 분리 진단한다.
“기존 성공률 미달이면 무조건 버그”로 단정하지 않는다.

도메인 랜덤화는 위치·회전의 속도 의존 오차, 연속된 가림, 지연·타임스탬프 오차, 깊이 누락,
오분류·추적 ID 전환, 장착 보정 오차, 질량·COM·마찰, 패드·구동 응답, 손 센서 노이즈를
포함한다. 장착 오차는 에피소드 내 고정 성분으로, 센서 노이즈는 시간 상관이 있는 성분으로
구분한다. 범위는 실측으로 좁혀 가며 물리적으로 모순된 질량·크기 조합은 제한한다.
이미지 경로에서는 조명·재질·노출·배경 변화도 평가한다.

## 9. 평가 계획과 완료 기준

### 9-1. 필수 평가 조건

1. 공·큐브·직육면체·원통 각각의 새로운 위치·크기·놓인 방향, 학습에 쓰지 않은 물체 인스턴스와 비정형 형상. 기존 형상의 크기 변화와 새로운 형상 일반화를 따로 집계.
2. 초기 일부 가림으로 재관측이 필요한 장면, 접근 중 자기 손에 가리는 장면, 인식 지연·연속 누락.
3. 같은 클래스의 다른 개체와 방해물, 가려진 타깃의 잘못된 추적 재연결.
4. 정면/top-down이 막혀 다른 후보가 필요한 장면, 후보 생성에 실패하는 장면.
5. 가벼움·무거움·낮은 마찰·COM 편차, 학습과 다른 외란 방향·위상.
6. 재시도 가능한 접촉 실패, 복구 불가능한 낙하, 검증 증거가 부족한 완전 가림.
7. 클래스 이름·CAD·주석 파지점을 제공하지 않는 물체와 unknown 검출 개체. 이름을 아는지와 실제 파지할 수 있는지를 분리 평가.
8. 공·원통이 접근 중 굴러 위치가 바뀌는 장면. 재관측으로 새 위치를 추적하고 안정 파지하는지 확인.

평가 세트는 학습·튜닝에 쓰지 않는다. 객체 인스턴스·장면 시드·카메라 조건·물리 프로파일·
평가기 버전을 저장한다. 시뮬은 초기 계획으로 학습 시드 3개, 주요 조건별 각 100회 이상을
사용하고 성공/전체 횟수와 95% 신뢰구간을 함께 보고한다. 실물은 물체·조건별 반복 횟수를
별도로 정해 공개하며, 적은 시연 횟수를 시뮬 통계와 합치지 않는다.

### 9-2. 비교 기준선

| 비교 대상 | 확인할 질문 |
|---|---|
| 현행 고정 오프셋·단일 closure 정책 | 새 성공 판정으로 재평가했을 때 격차가 무엇인가? 기존 높은 성공률과 직접 혼합하지 않음 |
| 새 인식 입력 + 고정 파지 규칙 | 인식 개선 이외에 RL 후보 선택·제어가 기여하는가? |
| 관측 후보의 생성기 최고 점수를 항상 선택 | RL의 명시적 후보 선택이 실제 파지 결과를 개선하는가? |
| 재관측을 제한한 새 정책 | 팔을 움직여 시야를 바꾸는 행동이 어려운 조건에서 도움이 되는가? |
| 기억 없음 / 촉각 없음 / G 손끝 표면 없음 | 가림 대응·접촉 피드백·손끝 기하 정보의 기여를 동일 조건으로 각각 비교 |
| 손1그룹 / 손3그룹 / 손20관절 | 동일 관측 출처·태스크 조건에서 표현력·학습량·성공률을 비교. 출력 확장만으로 성능이 개선됐다고 단정하지 않음 |
| 시범 초기화 act26 / 처음부터 학습 act26 | 같은 평가 세트에서 시범 초기화가 학습량과 일반화에 주는 영향을 비교 |
| 클래스·등록 모델을 사용하는 별도 기준선 | 기본 `obs_v3_366`는 클래스 입력이 없음. 이름·등록 모델 의존 기준선과 미등록 물체 조건의 성과를 비교 |

### 9-3. 지표와 잠정 목표

| 지표 | 정의·초기 목표 제안 |
|---|---|
| 전체 안정 파지 성공률 | §7 통과 수 / 첫 식별 후 시작한 전체 시도 수. 명목 조건 ≥90%, 정의한 어려운 조건 ≥80%를 초기 개발 목표로 둠 |
| 형상별·미학습 물체 성공률 | 공·큐브·원통·비정형별 성공/전체 횟수와 최저 형상 성공률. 기존 형상의 새 인스턴스, 새로운 형상, 클래스 미등록 조건을 따로 보고 |
| 최초 시도 / 재시도 포함 성공률 | 두 지표를 함께 보고. 복구로 늘어난 성공과 걸린 시간을 구분 |
| 오파지율 | 다른 개체 또는 비타깃 동시 파지 / 전체 시도. 초기 목표 ≤1% |
| 재관측 성능 | 재관측 성공률, 유효 후보 확보까지 시간, 재관측 필요 조건에서 기준선 대비 개선 |
| 파지 안정성 | 최대 팜 상대 이동·회전, 접촉 소실 시간, 정적/외란 통과율, 실제 인가 외란 |
| 운용 품질 | 전체 시간의 중앙값·p95, 재시도 수, 명령 제한 개입, 위험 충돌·낙하 횟수 |
| 손 개별 제어 품질 | 관절별 명령-실제각 오차·속도·제한 개입률, 자기충돌·스톨 지속시간. 접촉 중 의도된 추종 오차와 이상 누적을 구분 |
| 자체 성공 판정 품질 | 독립 계측 대비 거짓 성공률·검증 불가율. 검증 불가를 성공에서 제외 |
| 후보·인식 품질 | 후보 포함률, 타깃 추적 오류, 자세 오차, 유효 관측 나이·가림률 |

이 수치는 달성 결과나 장비 보증이 아니다. 물체·센서 사양 확인 후 **평가 전에** 확정한다.
위험 충돌은 평가에서 0회를 요구하되, 0회 관측만으로 위험 확률이 0이라고 해석하지 않는다.
첫 식별 자체가 실패한 경우는 이번 조건부 파지 성공률의 분모와 별도로 인식 실패율에 포함하여
전체 시스템 성능이 감춰지지 않게 한다. 검증 불가·타임아웃·중도 실패는 파지 분모에서 빼지 않는다.

**완료 선언에는 R1~R6의 증거, 실제 이미지 기반 평가, 실물 독립 계측 결과가 모두 필요하다.**
공·큐브·원통을 모두 포함한 기본 형상 평가와, 미학습 형상·클래스 미등록 조건의 평가도 필수다.
손잡이형 또는 큐브 하나의 성공만으로 다양한 물체의 자율 파지 목표를 달성했다고 선언하지 않는다.
시뮬 가상 추정기 성과만 있으면 “시뮬 정책 학습 완료”까지만 보고한다.

기존 체크포인트는 **비교 기준선 및 선택적 초기화 자산**으로 보존한다. 새 입력·손 출력·
이산 선택·기억 구조가 달라 `--initialize-from`으로 바로 호환된다고 가정하지 않는다.
의미가 같은 팔 관찰·출력 가중치의 부분 이식은 검증 후 실험할 수 있지만, 슬롯 확장
스크립트의 존재만으로 재사용이 성공한다고 단정하지 않는다. 처음부터 새로 학습하는
기준선도 함께 두고 전이 여부를 평가한다.
