# 용어집 (GLOSSARY)

이 저장소의 문서·코드·UI가 **같은 것을 같은 말로 부르기 위한** 표준 용어표다.
새 문서를 쓰거나 UI 라벨을 정할 때 여기 있는 표기를 쓴다. 여기 없는 용어를 새로 도입하면
**이 파일에 먼저 추가한다.**

> 용어가 흔들리면 "이 기능이 맞나?"가 반복된다. 이 저장소에서 실제로 그런 사고가 났던 항목은
> ⚠️로 표시했다.

## 1. 부르는 이름이 갈렸던 것 (⚠️ 주의)

| 표준 용어 | 쓰지 않는 표현 | 왜 |
|---|---|---|
| **손 / 그리퍼** (DG-5F-M-R) | "핸드", "5F", "테솔로" 혼용 | 문서마다 달라 검색이 안 됐다 |
| **팔** (UR16e) | "로봇", "매니퓰레이터" | "로봇"은 팔+손 결합체를 가리킨다 |
| **관절각[deg]** | "각도", "포즈" | UDP는 deg, RTDE·비전 내부는 rad — 단위를 반드시 붙인다 |
| **목표각** (`xDrive.target`) | "명령각", "포즈" | 실제 도달각(**실측각**)과 구분해야 한다 |
| **실측각** (Unity 물리 관절의 현재각) | "실제각" 단독 | 실물 센서값(**실물 실제각**)과 다르다 |
| **behavior 이름** (`DG5FPicknPlace`) | "모델명", "에이전트 이름" | Unity와 Python이 같은 과제를 가리키는 식별자 |
| **파지 확정**(grasp confirmed) | "잡음", "성공" | **성공**은 리프트까지 끝난 상태다 |
| **런(run)** | "학습", "실험" | 한 `--run-id`로 실행·저장한 학습 작업 하나 |
| **영역**(training area) | "환경", "인스턴스" | **환경**은 플레이어 프로세스 하나를 뜻한다 |
| **드라이런** | "테스트 모드" | 장비에 붙지 않고 수신값만 출력하는 상태 |
| **교시**(teach) | "프리 드라이브", "수동 모드" | 손에 힘을 풀어 사람이 자세를 잡게 하는 장비 기능 |
| **트윈 방향** | "동기화", "미러링" | sim→real / real→sim / 끊기 셋 중 하나 |
| **자동/수동** | "AI 모드", "조작 모드" | 목표를 정책이 정하는가 사람이 정하는가 |

⚠️ `Assets/Scripts`(복수, 현역)와 `Assets/Script`(단수, 잔재)는 **다른 폴더**다.
문서에 적을 때 반드시 s를 확인한다.

## 2. 하드웨어

| 용어 | 뜻 |
|---|---|
| **UR16e** | Universal Robots 협동로봇 팔. 가반 16 kg, 리치 900 mm |
| **DG-5F-M-R** | Tesollo 5지 그리퍼(오른손). SDK 모델 코드 `5f_right`, 20관절 |
| **AMR** | 엔스퀘어 이동 베이스. NR-200 커스텀으로 추정(미확정) |
| **FOUP** | 반도체 웨이퍼 캐리어. 최종 Pick & Place 대상 |
| **URSim** | UR가 배포하는 가상 컨트롤박스(도커). 실물과 같은 RTDE를 노출한다 |
| **DGManager** | Tesollo 공식 그리퍼 관리 프로그램. ⚠️ 켜 두면 SDK/Modbus가 붙지 못한다 |
| **펜던트** | UR 로봇 조작 화면. Local ↔ **Remote Control** 전환이 브리지 동작을 좌우한다 |

## 3. 강화학습

| 용어 | 뜻 |
|---|---|
| **정책**(policy) | 관찰을 받아 행동을 계산하는 학습 결과 |
| **관찰**(observation) | 정책에 주는 상태값. 현재 **57개** |
| **행동**(action) | 정책이 내놓는 제어값. 현재 **7개**(팔 6축 + 손 개폐 1축) |
| **보상**(reward) | 학습 중 행동을 평가하는 점수 |
| **에피소드** | 한 번의 시도 |
| **런(run)** | 여러 에피소드를 묶어 실행·저장한 학습 작업 |
| **PPO** | 이 프로젝트가 쓰는 학습 알고리즘 |
| **ONNX** | 학습한 정책을 추론용으로 저장하는 파일 형식 |
| **커리큘럼** | 난이도를 단계로 올리는 학습 방식. 여기서는 `grasp_stage` 1/2/3 |
| **게이트** | 지정 스텝까지 최소 지표를 못 채우면 실패로 보는 판정선 (G1~G4) |
| **폐합률**(closure) | 손이 얼마나 닫혔는가. 0(펴짐) ~ 1(주먹) |
| **전이**(transfer) | 학습된 가중치를 새 학습의 씨앗으로 쓰는 것 |
| **영역**(training area) | 학습 씬 안의 로봇 1대 + 물체 1개 묶음. 기본 40개 |
| **환경**(env) | 플레이어 프로세스 하나. 총 에이전트 = 영역 × 환경 |

## 4. 통신·브리지

| 용어 | 뜻 |
|---|---|
| **브리지** | Unity·비전의 관절 명령을 장비 통신으로 바꾸는 Python 프로그램 |
| **Receiver / Sender** | **Receiver = 밖에서 Unity로**, **Sender = Unity에서 밖으로** |
| **echo** | 장비에서 읽은 실제각을 Unity로 되돌려 보내는 것(`--echo-to-unity`) |
| **RTDE** | UR 컨트롤박스의 실시간 데이터 교환 인터페이스 |
| **servoJ** | RTDE의 관절 서보 명령. 단위 rad |
| **DGSDK** | Tesollo 그리퍼 SDK(DLL). `MoveServoJoint(float[20])`로 구동 |
| **슬루 제한**(slew limit) | 틱당 관절 최대 변화량을 걸어 급발진을 막는 것 |
| **디지털 트윈** | 실물을 따라가는(또는 실물이 따라오는) 화면 속 로봇 |

## 5. Unity

| 용어 | 뜻 |
|---|---|
| **씬**(Scene) | 로봇·물체·카메라를 배치한 실행 화면 |
| **컴포넌트** | 씬 오브젝트에 붙이는 기능 부품 |
| **프리팹**(Prefab) | 재사용하는 오브젝트 원본 |
| **`ArticulationBody`** | 물리 관절 |
| **`xDrive.target`** | 그 관절이 **도달하려는** 각도(= 목표각) |
| **플레이어**(Player) | Unity Editor 없이 실행하는 빌드 결과물 |
| **생성물** | 에디터 메뉴가 절차적으로 다시 만드는 씬·프리팹. **직접 편집 금지** |
| **어셈블리**(asmdef) | 컴파일 단위. 아래층이 위층을 참조하면 순환 참조로 깨진다 |

## 6. 설정·빌드

| 용어 | 뜻 |
|---|---|
| **정본** | 그 값의 유일한 출처. 다른 파일은 여기서 읽는다 |
| **`.env`** | 머신별 설정. git 비추적. `.env.example`을 복사해 만든다 |
| **원칙 1** | 하드코딩 금지 — 경로·IP·포트를 코드에 리터럴로 적지 않는다 |
| **원칙 2** | 새 머신 부트스트랩 보장 — 설치 직후 바로 학습을 시작할 수 있어야 한다 |
| **원칙 3** | 실행 가이드는 그대로 따라 하면 되는 수준으로 쓴다 |
| **URDF** | 로봇의 링크·관절·물리값·메시 경로를 적은 XML 모델 |
| **링크 접두사** | 왼손 `ll_`, 오른손 `rl_` |
| **멱등**(idempotent) | 다시 실행해도 결과가 같은 것 |

## 7. 문서 상태 표기

문서에서 폴더·파일의 상태를 말할 때 아래 네 가지만 쓴다.

| 표기 | 뜻 | 대응 |
|---|---|---|
| **현역** | 지금 쓰는 것 | 새 작업은 여기서 |
| **구세대** | 검증됐지만 이전 하드웨어 기준 | 참고만, 새 작업 금지 |
| **⛔ 폐기** | 쓰지 않는다. 되살리는 것을 전제하지 않는다 | 출발점으로 삼지 않는다 |
| **잔재** | 어디에도 연결돼 있지 않은 과거 코드 | 기록으로만 보존 |

## 8. 표기 규칙

- **단위를 반드시 붙인다**: `30 deg/s`, `0.12 m`, `0.3초`, `5006`(포트는 단위 없음)
- **파일 경로는 저장소 루트 기준 상대경로**, 구분자는 `/` (PowerShell도 받아들인다)
- **코드 식별자는 백틱**: `Dg5fPicknPlaceSpec.cs`, `--echo-to-unity`, `RTAUTO_UR_IP`
- **Unity 메뉴는 전체 경로**: `Tools > ML-Agents > Build DG5F PicknPlace Training Scene`
- **날짜는 절대 표기**: `2026-09-07` ("지난주", "최근" 금지)
- **미확정·미검증은 그렇게 쓴다**: "추정", "미검증", "코드 대조 기준"
